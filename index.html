GOOGLE CLOUD VISIONNão conectado

O projeto está preparado para receber os resultados da Cloud Vision API.

Importante: a Cloud Vision API fornece recursos como rótulos, rostos e SafeSearch, mas isso não significa que ela seja, sozinha, um detector de imagens geradas por IA. Para a parte “real x gerada”, o projeto deve conectar um modelo de detecção de conteúdo sintético/deepfake validado.

SOBRE O PROJETO

Tecnologia usada para prevenir danos digitais.

A proposta é ajudar a identificar sinais de manipulação e reduzir o compartilhamento irresponsável de imagens. O projeto prioriza privacidade, explicabilidade e encaminhamento seguro quando houver suspeita de abuso.
